# Usage Patterns

## Error handling

- Use typed errors where supported
- Document error classes in API sections

## Configuration

- Environment variables for services
- Default values and override precedence

## Performance

- Caching recommendations
- Pagination and rate limits for REST APIs

## Security

- Authentication methods
- Input validation and output encoding

## Versioning

- Semantic versioning for library APIs
- URL or header-based versioning for REST APIs
